WhysApp 0.21.1 gives the app its new name and puts the window buttons where a Mac app keeps them.

**Download WhysApp:** [Mac](https://github.com/Sowyu/whysapp/releases/download/v0.21.1/zapfast-v0.21.1-macos-universal.dmg)

This build is signed ad hoc and not notarized, so macOS warns the first time you open it. Right-click WhysApp in Applications, choose Open, then Open again.

![WhysApp with the window buttons beside the Chats title](https://github.com/Sowyu/whysapp/releases/download/v0.21.1/chat-dark.png)

## New

- **The app is called WhysApp** in the window title, menus, Dock, dialogs, notifications and every translation. Your linked account, chats and settings carry over untouched.

## Fixed

- **The traffic lights no longer crowd the left bar.** They sit level with the Chats title in one strip across the top, as in Mail and Notes, and the bar's buttons start below it.

## Known limitations

- The installed app is now WhysApp.app. If you installed 0.21.0, delete ZapFast.app from Applications after installing this one.
- Updates come from this fork's releases, and the app accepts only releases signed with ZapFast's update key, which this fork does not have. Install new versions from this page by hand.
